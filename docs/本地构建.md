# 本地构建指南

## 1. 环境要求

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| Node.js | **22+** | Capacitor 8 要求 |
| JDK | **21** | Temurin 推荐；设置 `JAVA_HOME` |
| Android SDK | platform 36 + build-tools 36 | 装 Android Studio 即可；或 cmdline-tools + `sdkmanager "platforms;android-36" "build-tools;36.0.0"` |
| Git | 任意 | 构建资源包时要拉站点源码 |

环境变量（Windows PowerShell 示例）：

```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.x.x-hotspot"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
```

## 2. 一键构建

```powershell
.\build.ps1            # release APK + 13 项校验
.\build.ps1 -Mode all  # 再带上 OTA 资源包
.\build.ps1 -Mode bundle   # 只出资源包（不需要 JDK/SDK）
```

```bash
./build.sh             # Linux / macOS，参数同上
```

手动等价命令：

```bash
npm install
npm run android:sync       # 生成 www（壳） + cap sync
npm run android:patch      # 权限/签名/版本/图标定制
npm run apk                # gradle assembleRelease → dist/
npm run verify             # apksigner + aapt2 校验
```

## 3. 首次构建会自动做

1. `cap add android`（如 `android/` 缺失）；
2. 下载 Gradle 发行版与依赖（约 300 MB，缓存在 `~/.gradle`）；
3. 缺失签名时回退 debug 签名并警告（正式版请先 `npm run keystore`）。

## 4. 常见报错

| 报错 | 原因 / 处理 |
| --- | --- |
| `Gradle build daemon disappeared unexpectedly` | 内存不足或被 OOM 杀。脚本已自动适配低内存（≤2GB 用 `-Xmx420m` 串行）；若仍失败：关掉其它吃内存的程序，或手动 `./gradlew --stop` 清理残留 daemon 后重试 |
| `Unable to start the daemon process ... Not enough space` | 上一次崩溃留下了僵尸 java 进程：任务管理器结束所有 `java.exe`（或 `kill -9`），再构建 |
| `SDK location not found` | 设置 `ANDROID_HOME`，或删除 `android/local.properties` 让脚本重写 |
| `Failed to install the following Android SDK packages` | 手动执行 `sdkmanager "platforms;android-36" "build-tools;36.0.0"` 并接受协议 |
| `keystore password was incorrect` | `keys/keystore.properties` 与 keystore 不匹配；或 CI 的 Secrets 配错 |
| 站点源码拉取失败 | 默认走 Gitee；可 `set CK_SITE_LOCAL=D:\path\to\repo` 指定本地克隆，或 `CK_SITE_REPO=<地址>` 换源 |

## 5. 产物清单

```
dist/
├── Ckarefulon-<versionName>-<versionCode>-release.apk   签名 APK
├── Ckarefulon-latest-release.apk                        同名副本（方便 CI 取用）
├── apk-info.json                                        版本/大小/SHA-256/签名别名
├── apk-verify.json                                      13 项校验结果
└── ota/
    ├── latest.json                                      OTA 清单
    ├── www-<版本>.zip                                    站点资源包
    └── staging/                                         解压视图（排查用，可删）
```

## 6. 调试技巧

- WebView 远程调试：`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` 或 `chrome://inspect`（release 包默认关闭，debug 包开启）。
- 看壳运行时日志：`adb logcat | grep -E "ck-ble|ck-update|Capacitor"`。
- 在 App 控制台（远程调试）执行：`CkApp.update.info()`、`CkApp.showAbout()`、`CkApp.bluetooth.BleClient.isEnabled()`。
